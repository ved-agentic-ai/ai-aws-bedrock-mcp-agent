📖 5. Section-Wise User Guide & Behind-the-Scenes Architecture Explainer

Click any section below to reveal deep technical breakdowns of what is happening under the hood!

🧠 1. How Amazon Bedrock & Model Context Protocol (MCP) Work Behind the Scenes ▼
Behind the Scenes:
1. When you enter a prompt, API Gateway forwards the HTTP request to the Agent Runtime Lambda.
2. Lambda calls bedrock_runtime.converse() with prompt text and the MCP JSON-RPC tools list.
3. Amazon Bedrock (Nova Micro) evaluates intent. If external data/memory is needed, it emits stopReason: tool_use.
4. Lambda invokes the MCP Tool Server Lambda (tools/call), executes DynamoDB or RAG queries, and feeds results back to Bedrock to synthesize the final ChatGPT-like answer!
📚 2. How RAG Document Chunking, S3 Vector Storage & Cosine Distance Work ▼
Behind the Scenes:
1. Document Ingestion: Uploaded PDF/TXT files are split into small 500-character text chunks.
2. Vector Embedding: Sentence Transformer model (all-MiniLM-L6-v2) converts text chunks into 384-dimensional floating-point vectors.
3. S3 Vector Storage: Vectors are saved to s3://agentic-mcp-knowledge-base/vectors/index.faiss.
4. Cosine Similarity Search: The query vector is compared against all S3 vectors using Cosine Similarity ($0.0 \to 1.0$). Chunks with score $>0.90$ are injected into the Bedrock Agent Prompt!
🎯 3. How QLoRA Fine-Tuning, LoRA Rank & Loss Curves Work ▼
Behind the Scenes:
1. Base Weights Frozen: The 7 Billion parameters of the base model (LLaMA 3 / Mistral) are frozen to 4-bit precision.
2. LoRA Adapters ($r=16$): Small trainable rank matrices are attached to Attention projection layers (q_proj, v_proj).
3. Supervised Fine-Tuning (SFT): Training runs on your custom instruction dataset (S3 path: s3://agentic-mcp-training-data/custom_dataset.jsonl).
4. Training Loss Drop: Loss decreases from 2.14 down to 0.31, and the final adapter weights file (adapter_model.bin ~14MB) is exported for deployment.
🤖 4. Custom Model Serving: Bedrock vs SageMaker Serverless vs Ollama ▼
Behind the Scenes:
• Amazon Bedrock On-Demand: Managed API call. Pay per input/output token ($0.000035/1k tokens).
• AWS SageMaker Serverless Inference: Deploys your custom fine-tuned LoRA model in a container. Scales to 0 when idle ($0 idle cost).
• Ollama Local Host: Runs models locally on your PC/GPU (`http://localhost:11434`) for 100% FREE execution.
💰 5. AWS Cost Optimization Strategy ($2/mo vs $1,070/mo) ▼
Behind the Scenes:
• Why Enterprise Dedicated Costs ~$1,070/mo: OpenSearch Serverless Vector Engine ($350/mo) + SageMaker 24/7 Dedicated GPU Endpoint ($720/mo).
• How AWS Serverless Cuts Cost to ~$2.00/mo: S3 Vector Storage ($0.20/mo) + SageMaker Spot Training ($0.70/job) + SageMaker Serverless Inference ($1.00/mo) + DynamoDB On-Demand TTL ($0.00/mo).

import json
import os
import boto3

bedrock_runtime = boto3.client('bedrock-runtime')
lambda_client = boto3.client('lambda')

def call_mcp_tool_server(action, name=None, arguments=None):
    payload = {"action": action}
    if name: payload["name"] = name
    if arguments: payload["arguments"] = arguments
    
    res = lambda_client.invoke(
        FunctionName=os.environ['MCP_SERVER_FUNCTION'],
        InvocationType='RequestResponse',
        Payload=json.dumps({"body": json.dumps(payload)})
    )
    res_payload = json.loads(res['Payload'].read().decode('utf-8'))
    return json.loads(res_payload.get('body', '{}'))

def handler(event, context):
    body = json.loads(event.get('body', '{}')) if isinstance(event.get('body'), str) else event.get('body', {})
    user_prompt = body.get('prompt', 'Hello AWS Bedrock!')
    session_id = body.get('session_id', 'session_101')

    # Step 1: Discover available MCP tools
    mcp_tools_res = call_mcp_tool_server('tools/list')
    tools_list = mcp_tools_res.get('tools', [])

    bedrock_tools = []
    for t in tools_list:
        bedrock_tools.append({
            "toolSpec": {
                "name": t["name"],
                "description": t["description"],
                "inputSchema": { "json": t["input_schema"] }
            }
        })

    system_prompt = [{"text": "You are Nova AI Assistant. Address the user directly in first-person with clean Markdown formatting."}]
    model_id = os.environ.get('BEDROCK_MODEL_ID', 'us.amazon.nova-micro-v1:0')
    messages = [{"role": "user", "content": [{"text": user_prompt}]}]

    # Step 2: First Converse API call
    response = bedrock_runtime.converse(
        modelId=model_id,
        messages=messages,
        system=system_prompt,
        toolConfig={"tools": bedrock_tools} if bedrock_tools else None
    )

    output_message = response['output']['message']
    stop_reason = response.get('stopReason')

    if stop_reason == 'tool_use':
        tool_requests = [c for c in output_message['content'] if 'toolUse' in c]
        tool_results = []

        for tr in tool_requests:
            t_use = tr['toolUse']
            t_args = t_use['input']
            if 'session_id' not in t_args: t_args['session_id'] = session_id
            
            exec_res = call_mcp_tool_server('tools/call', name=t_use['name'], arguments=t_args)
            tool_results.append({
                "toolResult": {
                    "toolUseId": t_use['toolUseId'],
                    "content": [{"json": exec_res.get('result', {})}]
                }
            })

        messages.append(output_message)
        messages.append({"role": "user", "content": tool_results})

        # Step 3: Second Converse API call to synthesize final response
        final_response = bedrock_runtime.converse(
            modelId=model_id,
            messages=messages,
            system=system_prompt,
            toolConfig={"tools": bedrock_tools} if bedrock_tools else None
        )
        final_content = final_response['output']['message']['content']
        final_text = "".join([b.get('text', '') for b in final_content if 'text' in b])
        return {
            "statusCode": 200,
            "body": json.dumps({"response": final_text, "mcp_tools_executed": [tr['toolUse']['name'] for tr in tool_requests]})
        }
    else:
        return {"statusCode": 200, "body": json.dumps({"response": output_message['content'][0]['text']})}
import json
import os
import boto3
import time
from boto3.dynamodb.conditions import Key

dynamodb = boto3.resource('dynamodb')

def list_mcp_tools():
    return [
        {
            "name": "query_database",
            "description": "Query session history from DynamoDB",
            "input_schema": {
                "type": "object",
                "properties": { "session_id": { "type": "string" } },
                "required": ["session_id"]
            }
        },
        {
            "name": "save_session_data",
            "description": "Save session item to DynamoDB",
            "input_schema": {
                "type": "object",
                "properties": { "session_id": { "type": "string" }, "content": { "type": "string" } },
                "required": ["session_id", "content"]
            }
        }
    ]

def execute_mcp_tool(tool_name, arguments):
    session_id = arguments.get("session_id", "session_101")
    table = dynamodb.Table(os.environ['TABLE_NAME'])

    if tool_name == "query_database":
        res = table.query(
            KeyConditionExpression=Key('SessionId').eq(session_id),
            ScanIndexForward=False,
            Limit=10
        )
        items = res.get('Items', [])
        for item in items:
            for k, v in list(item.items()):
                if hasattr(v, '__float__'): item[k] = float(v)
        return {"status": "success", "items": items, "count": len(items)}

    elif tool_name == "save_session_data":
        content = str(arguments.get("content", "User session memory entry"))
        now = int(time.time())
        table.put_item(Item={
            'SessionId': session_id,
            'Timestamp': now,
            'Content': content,
            'TTL': now + 86400
        })
        return {"status": "success", "message": f"Successfully stored session item for {session_id} in DynamoDB table!"}

    return {"error": f"Tool {tool_name} not found"}

def handler(event, context):
    body = json.loads(event.get('body', '{}')) if isinstance(event.get('body'), str) else event.get('body', {})
    action = body.get('action', 'tools/list')

    if action == 'tools/list':
        return {"statusCode": 200, "body": json.dumps({"tools": list_mcp_tools()})}
    elif action == 'tools/call':
        result = execute_mcp_tool(body.get('name'), body.get('arguments', {}))
        return {"statusCode": 200, "body": json.dumps({"result": result})}
